Status, done properly

An Azure page cannot contact a private home server. The reliable next step is a small authenticated status endpoint on your network that exposes only safe measurements—online state, disk and array health, Docker count, and backup result.

Private by design

  1. Keep Unraid administration LAN-only.
  2. Add sign-in at Azure Static Web Apps before sharing this hub.
  3. Use a tunnel or reverse proxy only for individual apps you choose to share.
